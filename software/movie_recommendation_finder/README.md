# Movie Recommendation Finder

Local Python recommender. No API key. Pick a film you like, a genre, or a mood; it scores a built-in catalog.

This folder is written to become its own GitHub repo (`movie-recommendation-finder`) later. On the portfolio it also runs as a live page at `/apps/movies`.

## CLI

```powershell
py -3 -m software.movie_recommendation_finder --like "Arrival" --mood thoughtful
py -3 -m software.movie_recommendation_finder --genre comedy --genre romance
```
